# Google Apps Script 後端設定教學

這個資料夾裡的 `Code.gs` 是房屋報修系統的後端。它會把房客送出的報修單寫進
Google 試算表、把照片存進 Google Drive，並寄 Email 通知你。整個過程**不需要自架
伺服器，也不用付費**。

完成以下步驟後，把拿到的網址貼進 `src/config.js` 的 `ENDPOINT_URL`，系統就會從
Demo 模式切換成正式運作。

---

## 步驟

### 1. 建立試算表

1. 到 [Google 試算表](https://sheets.google.com) 建立一份新的空白試算表。
2. 取個名字，例如「房屋報修紀錄」。

### 2. 貼上後端程式

1. 在試算表上方選單點 **擴充功能 → Apps Script**。
2. 把預設的 `Code.gs` 內容整個刪掉，貼上本資料夾 `Code.gs` 的全部內容。
3. 修改最上方兩個設定：
   - `NOTIFY_EMAIL`：改成你要收通知的 Email（預設已填 `sdlcheng@gmail.com`）。
   - `SHEET_NAME`：通常維持 `報修單` 即可，程式會自動建立這個分頁。
4. 按 💾 儲存。

### 3. 部署成 Web 應用程式

1. 右上角點 **部署 → 新增部署作業**。
2. 類型（齒輪圖示）選 **網頁應用程式**。
3. 設定：
   - **執行身分**：以我（你自己）的身分執行。
   - **誰可以存取**：選 **所有人**（這樣房客打開網頁才能送出）。
4. 按 **部署**，第一次會要求授權，依指示允許（會跳「Google 尚未驗證這個應用程式」
   →「進階」→「前往…(不安全)」，這是你自己的腳本，可放心允許）。
5. 複製最後給你的 **網頁應用程式網址**（長得像
   `https://script.google.com/macros/s/AKfy.../exec`）。

### 4. 接到前端

打開 `src/config.js`，把網址貼進去：

```js
export const ENDPOINT_URL = 'https://script.google.com/macros/s/AKfy.../exec'
```

存檔後重新整理網頁，最上方的黃色「Demo 模式」提示消失，就代表正式接通了。

## 常見問題

- **改了 `Code.gs` 後沒生效？** 要重新「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選
  『新版本』→ 部署」，新程式才會上線。
- **房客送出失敗 / CORS 錯誤？** 確認部署時「誰可以存取」選的是 **所有人**。
- **照片打不開？** 程式已自動把照片設成「知道連結的人可檢視」；若公司 Google 帳號有
  共用限制，可能需要放寬 Drive 分享政策。
- **想多人收通知？** 把 `NOTIFY_EMAIL` 改成用逗號分隔的多個信箱即可。
