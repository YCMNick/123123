# 差一度：自動化測試與數值模擬

每次改遊戲前後跑一次：

```bash
npm run test:game
```

`test:game` 會先從 `game/` 重新組出 `public/game/index.html`，再跑測試。全部通過，代表「遊戲沒有壞掉」，而且「數值沒有崩潰」。

## 測了什麼

| 檔案 | 內容 |
|---|---|
| `smoke.test.js` | 用真的滑鼠、鍵盤走完整流程：首頁十大關卡、關卡照順序解鎖（前一小關過了才開下一關、整個大關過完才開下一大關）、地圖由上往下、進度與「繼續」、倒數、拖曳和放大鏡、微調、暫停、過關、失敗重來、動物會動且轉正後安靜、100 關畫面、中英切換（含畫布上沒有殘留中文）、背景音樂與音效分開開關、關卡卡片上選難度（各難度紀錄）、站點與清單標出破過的最高難度、連輸兩次的「改用簡單」、卡住 8 秒的提示、App 版解鎖規則、舊版存檔搬移，以及 5 種螢幕寬度的版面 |
| `rules.test.js` | 規則和計分：10 × 10 關的結構與中英內容、每關物品數與難度遞增、陷阱和連動設定合理、0.5° 和 0.1° 的判定門檻、不吸附、練習關時間加倍、禪模式不計時、慢拖精細模式（¼ 增益）、三組連動、要倒過來才對的海市蜃樓、動物轉正時的叫聲、+2 秒只給一次、緊張模式的時間點、連輸放水、斜塔只有過關才計分、三種難度、結算評語（每大關五種等級、不連續重複）、Q 版音效（每件物品都有聲音、全部能正常合成）、計分公式、單調性 |
| `fuzz.test.js` | 極端操作：4 輪各 300 個隨機操作（含切語言、開關音樂音效）、超大角度、上萬次微調、狂拖、多指觸控、倒數中切換畫面、完成鍵連按 |
| `simulation.test.js` | 3 種難度 × 100 關 × 3 種玩家，各自動玩 60 局（共 54,000 局，多個分頁平行跑）：每局結果合法、參考機器人分數精確、14 項設計目標（含每個大關內難度遞增、簡單模式新手也過得了、三種難度勝率依序遞減、掛機 0 分）、與基準線比較 |

## 兩支探針（不在測試裡，手動跑）

- `node game/tools/probe-touch.mjs`：手機上手指拖曳的角度解析度，以及一次放手落在容差內的機率（快拖 vs 慢拖精細模式）。
- `node game/tools/probe-funnel.mjs`：模擬玩家從 1-1 開始、輸了重來（含放水加時）、過了往下，看幾次嘗試、幾分鐘能過前 3 關。

## 看報告

跑完會產生 `test-results/game-sim/report.md`，內容有各關勝率、分數分布、星數分布、設計目標達成狀況，以及和基準線的差距。

- ❌ 強制目標沒達成：測試失敗。
- ⚠️ 已知問題：只提醒，不算失敗。這些就是之後優化要處理的項目。

## 改了數值之後

1. 跑 `npm run test:game`，看報告。關卡時間不對時，用 `node game/tools/calibrate.mjs --world <大關 key>` 重新校準（寫入 `game/times.json`）。
2. 如果數值改變是你**刻意**的，就跑 `npm run test:game:baseline` 更新基準線，並把 `baseline.json` 一起 commit。
3. 設計目標寫在 `balance.config.js`，可以調整。

## 三種難度

| 難度 | 名稱 | 算對齊的誤差 | 時間 | 放大鏡 | 分數 |
|---|---|---|---|---|---|
| 簡單 | 看到會歪頭 | 1.5° | ×1.35 | 度數＋往哪轉 | ×0.6 |
| 普通 | 忍不住伸手 | 0.5° | ×1 | 度數 | ×1 |
| 困難 | 不轉正睡不著 | 0.2° | ×0.85 | 只放大 | ×1.5 |

模擬時假設：放大鏡沒有度數時，玩家瞄得比較不準（誤差 ×1.6）；有方向提示時稍微準一點（×0.9）。

## 重要假設

模擬用的三種玩家（新手、一般、熟手）是**推估的模型**，不是真實玩家的數據。有了試玩數據後，請更新 `balance.config.js` 裡的 `PROFILES`。

## 可調參數

- `GAME_SIM_RUNS=30 npm run test:game`：減少模擬局數，跑得比較快（預設 60）。
- `GAME_SIM_PAGES=4 npm run test:game`：同時模擬幾個遊戲分頁（預設 CPU 核心數的一半，2～8）。
- `GAME_SIM_CURVE_RUNS=200`：「每個大關內逐關變難」這個目標另外跑的一般玩家局數（預設 200，相鄰關卡比較需要較準的數字）。
- `GAME_FUZZ_ACTIONS=1000 npm run test:game`：增加隨機操作的次數。
